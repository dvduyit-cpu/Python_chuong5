1. CHUỖI – STRING (CHUỖI KÝ TỰ)

1.1. Chuỗi là gì?

Chuỗi (str) là dãy ký tự. Chuỗi có thể chứa chữ, số, khoảng trắng và ký tự đặc biệt. Chuỗi là kiểu dữ liệu immutable, nghĩa là không sửa trực tiếp từng ký tự.

1.2. Index

Python đánh chỉ số từ 0. Chỉ số âm đi từ cuối chuỗi.

text = "Python"

# text[0] lấy ký tự đầu tiên
print(text[0])

# text[-1] lấy ký tự cuối cùng
print(text[-1])
Kết quả:
P
n

1.3. Slicing

Cú pháp: text[start:stop:step]. Vị trí stop không được lấy.

text = "Python"

# Lấy từ vị trí 0 đến trước vị trí 3
print(text[0:3])

# Từ đầu đến trước vị trí 4
print(text[:4])

# Từ vị trí 2 đến cuối
print(text[2:])

# Bước -1 để đảo chuỗi
print(text[::-1])
Kết quả:
Pyt
Pyth
thon
nohtyP

1.4. Nối chuỗi

first_name = "An"
last_name = "Nguyen"

# Dùng + để nối chuỗi
full_name = first_name + " " + last_name

print(full_name)
Kết quả:
An Nguyen

2. ENCODING (MÃ HÓA KÝ TỰ) VÀ REGEX (BIỂU THỨC CHÍNH QUY)

2.1. Encoding là gì?

Máy tính lưu ký tự thành byte. Encoding là quy tắc chuyển ký tự thành byte. UTF-8 được dùng rất phổ biến và hỗ trợ tiếng Việt.

text = "Cà Mau"

# Chuyển chuỗi sang bytes bằng UTF-8
data = text.encode("utf-8")

print(data)

# Chuyển bytes trở lại chuỗi
decoded = data.decode("utf-8")

print(decoded)
Kết quả:
b'C\xc3\xa0 Mau'
Cà Mau

2.2. Khi nào cần encoding?

  • Đọc/ghi file.
  • Gửi dữ liệu qua mạng.
  • Xử lý tiếng Việt.

2.3. Regex là gì?

Regex là mẫu dùng để tìm kiếm hoặc kiểm tra chuỗi. Python dùng module re.

import re

text = "Email: an@example.com"

# \S+ nghĩa là một hoặc nhiều ký tự không phải khoảng trắng
# @ là ký tự @
# \. là dấu chấm thật
match = re.search(r"\S+@\S+\.\S+", text)

if match:
    # group() lấy phần chuỗi khớp mẫu
    print(match.group())
Kết quả:
an@example.com
Lưu ý: regex mạnh nhưng khó đọc. Bài đơn giản nên ưu tiên string methods.

4. TUPLE (BỘ GIÁ TRỊ) VÀ UNPACKING (GIẢI NÉN)

4.1. Tuple là gì?

Tuple có thứ tự giống list nhưng immutable, nên phù hợp cho dữ liệu không nên thay đổi.

point = (10, 20)

print(point[0])
print(point[1])

4.2. Khi nào dùng?

  • Tọa độ.
  • Ngày tháng.
  • Kết quả trả về nhiều giá trị.

4.3. Unpacking

point = (10, 20)

# Giải nén hai phần tử vào hai biến
x, y = point

print(x)
print(y)
Kết quả:
10
20

4.4. Unpacking với *

numbers = [1, 2, 3, 4, 5]

# first nhận phần tử đầu
# middle nhận các phần tử giữa
# last nhận phần tử cuối
first, *middle, last = numbers

print(first)
print(middle)
print(last)
Kết quả:
1
[2, 3, 4]
5

5. SET (TẬP HỢP) – KHÔNG TRÙNG

5.1. Set là gì?

Set chứa phần tử duy nhất, không trùng và không đảm bảo thứ tự.

numbers = {1, 2, 2, 3, 3}

# Các phần tử trùng tự bị loại
print(numbers)
Kết quả:
{1, 2, 3}

5.2. Khi nào dùng?

  • Loại trùng.
  • Kiểm tra phần tử tồn tại.
  • Phép toán tập hợp.

5.3. Hợp, giao, hiệu

a = {1, 2, 3}
b = {3, 4, 5}

# Hợp: tất cả phần tử
print(a | b)

# Giao: phần tử chung
print(a & b)

# Hiệu: có trong a nhưng không có trong b
print(a - b)
Kết quả:
{1, 2, 3, 4, 5}
{3}
{1, 2}

6. DICT / DICTIONARY (TỪ ĐIỂN) – KHÓA VÀ GIÁ TRỊ

6.1. Dict là gì?

Dictionary lưu dữ liệu theo cặp key: value. Key phải duy nhất.

student = {

# Truy cập trực tiếp theo key

# get() an toàn hơn nếu key có thể không tồn tại

6.3. get() và []

# Thêm key mới

# Sửa giá trị key đã có

6.5. Duyệt dict

# items() trả từng cặp key-value
for key, value in student.items():

8. SHALLOW COPY (SAO CHÉP NÔNG) VÀ DEEP COPY (SAO CHÉP SÂU)

8.1. Gán không phải sao chép

list_a = [1, 2, 3]

# list_b không phải bản sao độc lập
# Hai biến cùng trỏ tới một list
list_b = list_a

list_b[0] = 99

print(list_a)
print(list_b)
Kết quả:
[99, 2, 3]
[99, 2, 3]

8.2. Shallow copy

Shallow copy tạo container ngoài mới nhưng dữ liệu lồng bên trong vẫn có thể dùng chung.

original = [[1, 2], [3, 4]]

# copy() tạo list ngoài mới
shallow = original.copy()

# Sửa list con
shallow[0][0] = 99

print(original)
print(shallow)
Kết quả:
[[99, 2], [3, 4]]
[[99, 2], [3, 4]]

8.3. Deep copy

import copy

original = [[1, 2], [3, 4]]

# deepcopy sao chép cả cấu trúc lồng nhau
deep = copy.deepcopy(original)

deep[0][0] = 99

print(original)
print(deep)
Kết quả:
[[1, 2], [3, 4]]
[[99, 2], [3, 4]]
Cách giảng: shallow copy giống sao chép bìa hồ sơ nhưng giấy bên trong vẫn dùng chung; deep copy là sao chép cả bìa lẫn giấy bên trong.

9. MUTABLE (CÓ THỂ THAY ĐỔI) VÀ IMMUTABLE (KHÔNG THỂ THAY ĐỔI TRỰC TIẾP)

9.1. Mutable

Đối tượng có thể thay đổi sau khi tạo: list, dict, set.

9.2. Immutable

Đối tượng không sửa trực tiếp: int, float, str, tuple.

9.3. List truyền vào hàm

def them_diem(danh_sach_diem):
    # append() thay đổi trực tiếp list nhận được
    danh_sach_diem.append(10)


danh_sach_diem = [7, 8, 9]

them_diem(danh_sach_diem)

# List gốc bên ngoài cũng thay đổi
print(danh_sach_diem)
Kết quả:
[7, 8, 9, 10]

9.4. Chuỗi truyền vào hàm

def doi_ten(ten):
    # Chuỗi immutable
    # upper() tạo chuỗi mới
    ten = ten.upper()

    # Trả chuỗi mới
    return ten


ten_sinh_vien = "An"

ten_moi = doi_ten(ten_sinh_vien)

print(ten_sinh_vien)
print(ten_moi)
Kết quả:
An
AN

9.5. Vì sao cần hiểu mutable?

  • Tránh sửa nhầm dữ liệu gốc.
  • Biết khi nào cần copy.
  • Hiểu tác dụng phụ khi truyền list/dict/set vào hàm.

10. BÀI TẬP TỔNG HỢP

Bài 1. Phân tích câu

  1. Nhập câu.
  2. strip().
  3. split().
  4. Đếm từ.
  5. In chữ hoa.
# Nhập chuỗi
text = input("Nhập một câu: ")

# Bỏ khoảng trắng thừa
text = text.strip()

# Tách thành danh sách từ
words = text.split()

# Đếm số từ
word_count = len(words)

print("Số từ:", word_count)

# Tạo chuỗi chữ hoa
print("Chữ hoa:", text.upper())

Bài 2. Lọc điểm đạt

  1. Tạo list điểm.
  2. Dùng comprehension lọc >=5.
  3. Tính trung bình điểm đạt.
scores = [4, 5, 7, 8, 3, 9]

# Chỉ giữ điểm đạt
passed_scores = [
    score
    for score in scores
    if score >= 5
]

# Tính trung bình
average = sum(passed_scores) / len(passed_scores)

print("Điểm đạt:", passed_scores)
print(f"Trung bình: {average:.2f}")
Kết quả:
Điểm đạt: [5, 7, 8, 9]
Trung bình: 7.25

Bài 3. Hồ sơ sinh viên bằng dict

  1. Tạo dict name, age, scores.
  2. Tính trung bình scores.
  3. Thêm key average.
  4. Duyệt items().
student = {
    "name": "An",
    "age": 18,
    "scores": [7.5, 8.0, 6.5]
}

# Lấy list điểm
scores = student["scores"]

# Tính trung bình
average = sum(scores) / len(scores)

# Thêm dữ liệu mới vào dict
student["average"] = average

# In toàn bộ
for key, value in student.items():
    print(f"{key}: {value}")

Bài 4. Quan sát shallow copy

  1. Tạo list lồng nhau.
  2. copy().
  3. Sửa phần tử trong list con.
  4. In cả hai.
  5. Giải thích vì sao cùng thay đổi.
original = [
    ["An", 8],
    ["Binh", 7]
]

# Shallow copy chỉ sao chép list ngoài
copied = original.copy()

# Hai biến vẫn dùng chung list con
copied[0][1] = 10

print("Original:", original)
print("Copied:", copied)
Kết quả:
Original: [['An', 10], ['Binh', 7]]
Copied: [['An', 10], ['Binh', 7]]

  2. Dùng strip() (loại khoảng trắng đầu/cuối).
  3. Dùng title() (viết hoa đầu từ).
  4. Dùng split() (tách chuỗi thành list) để đếm số từ.
  5. In họ tên chuẩn và số từ.
Dữ liệu mẫu:
   nguyen van an
Kết quả mong đợi:
Họ tên chuẩn: Nguyen Van An
Số từ: 3
# Nhập họ tên từ bàn phím
ho_ten = input("Nhập họ tên: ")

# strip() = loại khoảng trắng ở đầu và cuối
ho_ten = ho_ten.strip()

# title() = viết hoa chữ cái đầu mỗi từ
ho_ten = ho_ten.title()

# split() = tách chuỗi thành danh sách từ
cac_tu = ho_ten.split()

# len() = đếm số phần tử trong danh sách
so_tu = len(cac_tu)

print("Họ tên chuẩn:", ho_ten)
print("Số từ:", so_tu)

Bài 2. Đếm nguyên âm trong chuỗi

Tên file: cuoichuong_02_dem_nguyen_am.py

  1. Nhập một chuỗi.
  2. Chuyển chuỗi về chữ thường bằng lower().
  3. Duyệt từng ký tự.
  4. Nếu ký tự thuộc tập a, e, i, o, u thì tăng biến đếm.
  5. In tổng số nguyên âm.
Dữ liệu mẫu:
Python is useful
Kết quả mong đợi:
Số nguyên âm: 5
# Nhập chuỗi
chuoi = input("Nhập chuỗi: ")

# lower() = chuyển toàn bộ về chữ thường
chuoi = chuoi.lower()

# Biến đếm ban đầu bằng 0
so_nguyen_am = 0

# Duyệt từng ký tự trong chuỗi
for ky_tu in chuoi:
    # in = kiểm tra một phần tử có thuộc chuỗi/tập hợp hay không
    if ky_tu in "aeiou":
        so_nguyen_am += 1

print("Số nguyên âm:", so_nguyen_am)

  3. Duyệt từng điểm.
  4. Nếu điểm hiện tại lớn hơn thì cập nhật cao nhất.

Cao nhất: 9.0

# Khởi tạo bằng phần tử đầu tiên
cao_nhat = diem[0]
thap_nhat = diem[0]

# Duyệt từng điểm
for diem_so in diem:
    if diem_so > cao_nhat:
        cao_nhat = diem_so

    if diem_so < thap_nhat:
        thap_nhat = diem_so

print("Cao nhất:", cao_nhat)
print("Thấp nhất:", thap_nhat)

Bài 9. So sánh shallow copy và deep copy

Tên file: cuoichuong_09_copy.py

  1. Tạo list lồng nhau.
  2. Tạo một shallow copy bằng copy().
  3. Tạo một deep copy bằng copy.deepcopy().
  4. Sửa phần tử trong list con của từng bản sao.
  5. Quan sát dữ liệu gốc.
import copy

# Dữ liệu gốc có list lồng nhau
du_lieu_goc = [[1, 2], [3, 4]]

# copy() = shallow copy, sao chép nông
ban_sao_nong = du_lieu_goc.copy()

# deepcopy() = deep copy, sao chép sâu
ban_sao_sau = copy.deepcopy(du_lieu_goc)

# Sửa phần tử lồng trong shallow copy
ban_sao_nong[0][0] = 99

print("Sau shallow copy:")
print("Gốc:", du_lieu_goc)
print("Bản sao nông:", ban_sao_nong)

# Sửa deep copy
ban_sao_sau[1][0] = 88

print("Sau deep copy:")
print("Gốc:", du_lieu_goc)
print("Bản sao sâu:", ban_sao_sau)
Ý cần nhận xét:
Shallow copy có thể làm dữ liệu lồng nhau của bản gốc thay đổi.
Deep copy độc lập với dữ liệu gốc.

Bài 10. Mutable và immutable khi truyền vào hàm

Tên file: cuoichuong_10_mutable.py

  1. Tạo một hàm thêm điểm vào list.
  2. Tạo một hàm đổi chuỗi thành chữ hoa.
  3. Gọi hai hàm.
  4. Quan sát list bị thay đổi trực tiếp nhưng chuỗi gốc không đổi.
# List là mutable = có thể thay đổi
def them_diem(danh_sach_diem):
    # append() thay đổi trực tiếp list được truyền vào
    danh_sach_diem.append(10)


# Chuỗi là immutable = không thể thay đổi trực tiếp
def doi_ten(ten):
    # upper() tạo chuỗi mới
    ten_moi = ten.upper()

    # Trả chuỗi mới
    return ten_moi


danh_sach_diem = [7, 8, 9]
ten_sinh_vien = "An"

# Hàm này làm list gốc thay đổi
them_diem(danh_sach_diem)

# Hàm này tạo chuỗi mới
ten_moi = doi_ten(ten_sinh_vien)

print("Danh sách điểm:", danh_sach_diem)
print("Tên gốc:", ten_sinh_vien)
print("Tên mới:", ten_moi)
Kết quả:
Danh sách điểm: [7, 8, 9, 10]
Tên gốc: An
Tên mới: AN
